# 学段与育人路由

## 育人素养

每次任务从下列五项中选择最相关的2—3项，不机械全部出现。

| 素养 | 在黑板报中的体现 |
|---|---|
| 文化理解 | 知道历史、人物、节日、器物或意象为何与主题有关 |
| 审美感知 | 感受色彩、笔势、空间和材料表达的情绪 |
| 艺术表现 | 看见标题、正文、图像和材料如何共同表达意义 |
| 创意实践 | 同一主题以原创方式表达，不依赖通用模板 |
| 价值判断与行动 | 从板报中获得一个问题、选择、规则或可实践行动 |

育人价值不能依靠额外增加“德育意义”栏目完成，必须进入标题命题、核心意象、正文事实与故事、画面情绪，以及学生真实生活。

## 主题转译

主题可以跨学段，学段路由只决定生活入口、标题语言、正文深度、核心意象、画面情绪与行动连接，不决定主题只能属于某个年龄段。

用户已经给出的价值方向、节日或纪念要求应先作为内容约束保留，再进行年龄适配：小学从具体人物、生活场景、规则和小事进入；初中从历史故事、同伴关系、公共规则、选择与责任进入；高中从历史因果、社会伦理、文化判断、时代责任和个人位置进入。

| 主题方向 | 优先育人内核 | 避免套板 |
|---|---|---|
| 核心价值观、学生素养、五育 | 把抽象价值转为适龄情境、判断、品格与行动 | 机械罗列概念、成人化表述、只写口号 |
| 红色精神、革命与重大纪念 | 尊重事实，理解人物选择、精神传承、和平与责任 | 虚构史实、符号堆叠、以红色装饰替代内容 |
| 新学期、班级文化、成长 | 归属、习惯、目标与共同成长 | 火箭、帆船、星空机械套用 |
| 阅读、经典、传统文化 | 理解、对话、文化根脉与当代表达 | 书堆、祥云、古建筑简单拼贴 |
| 爱国、历史、纪念 | 历史理解、责任、和平与传承 | 只堆红色、旗帜、长城和口号 |
| 安全、法治、文明 | 风险识别、规则理解与正确行动 | 恐吓、事故猎奇、纯口号 |
| 心理健康、生命成长 | 自我理解、韧性、求助与同伴支持 | 强迫积极、彩虹爱心笑脸堆砌 |
| 科技、AI、创新 | 科学精神、判断力、人的主体性与技术责任 | 机器人、芯片和蓝光堆叠 |
| 劳动、生态、自然 | 实践、责任、观察与真实行动 | 空泛的“人人有责” |
| 节日、节气、民俗 | 文化来源、生活经验与地方记忆 | 通用节庆符号全部堆入 |

## 学段路由

### 小学低段（1—2年级）

- 认知入口：自己、家庭、班级和具体生活。
- 育人重点：习惯、关爱、规则、归属与可执行行动。
- 标题与正文：明白、温暖、孩子能复述；使用童声短句、简短故事与行动提示。
- 内容：1个核心句加2—4个故事、行动或知识小单元。
- 视觉：绘本场景、卡纸、照片、小报和简单重复元素；单个元素清楚、易描画或剪贴。
- 避免：抽象长文、复杂透视、写实人物、成人海报感和过度空洞。

### 小学高段（3—6年级）

- 认知入口：因果关系、合作、集体和文化好奇。
- 育人重点：责任、合作、自我管理和文化兴趣。
- 标题与正文：清楚、有文气但不难懂；可用事实、故事、行动、小知识和学生表达。
- 内容：3—5个内容单元，可含照片、小报和学生作品。
- 视觉：场景与模块结合、轻量信息图、剪纸和拼贴，错落但便于阅读和制作。
- 避免：幼儿园化、空模块、普通PPT版式和照搬初高中杂志风。

### 初中

- 认知入口：身份认同、同伴关系、规则、选择和初步公共意识。
- 育人重点：自律、尊重、同理、责任和初步判断。
- 标题与正文：有少年感，可包含问题与选择；使用真实案例、观点、问题、短评和行动提示。
- 内容：主题教育或知识任务通常有2—3段实质内容，并至少包含一个事实、问题或行动连接。
- 视觉：由小学模块感向高中字图共生过渡，可用青年编辑、主景环绕、限制色版画或斜向题字。
- 避免：低龄化装饰和直接复制高中复杂视觉特刊。

### 高中

- 认知入口：历史、社会、伦理、未来和个人在时代中的位置。
- 育人重点：责任担当、文化理解、独立判断、人的主体性和现实选择。
- 标题与正文：可诗性或概念化，但语义准确；可用史料、引文、短评、美文、人物片段、问题和简要论证。
- 内容：主题教育或知识任务通常有2—4段文字序列，以及1—2条引文、题跋或短句；节庆和纪念型可更多使用真实留言。文字默认具有约半板存在感，但不做像素级硬比例计算。
- 视觉：传统手绘黑板为主，可用横向长卷、题字驱动、主景环绕或手绘视觉特刊，文字与红绸、山势、浪线、花枝、书卷、道路或光线交融。
- 避免：低龄化、少字概念海报、摄影级细节和复杂三维材质。

## 同一主题的学段示例

示例用于说明方向，不是固定标题库。

### 人工智能

- 小学：《聪明使用AI》——认识工具、保护隐私、向老师求证。
- 初中：《智启未来，慎思而行》——核验信息、理解规则、避免依赖。
- 高中：《算法之外，何以为人》——技术伦理、劳动变化、判断力和人的主体性。

### 心理健康

- 小学：《我的情绪会说话》——认识情绪、表达需要、主动求助。
- 初中：《听见心里的声音》——同伴关系、自尊、边界和支持。
- 高中：《与压力相处，也与自己和解》——压力、自我价值、选择、韧性和求助路径。

### 爱国、历史与红色主题

- 小学：从家乡、真实人物、身边建设者、英雄故事和可做的小事进入。
- 初中：从历史事件、人物选择、文明规则、集体责任与和平意识进入。
- 高中：从史料、历史因果、精神传承、现实处境与青年责任进入。

### 阅读与传统文化

- 小学：故事、人物、器物和节日生活。
- 初中：经典与自我经验的对话，以及文化为何值得传承。
- 高中：经典的当代意义、传统与创新、文化判断与个人位置。

### 核心价值观与学生素养

- 小学：友善、诚信、规则、劳动和班级生活中的具体行为。
- 初中：同伴交往、公共规则、网络文明、责任选择和五育发展。
- 高中：公民责任、社会参与、法治意识、价值判断和青年担当。

### 节气与传统节日

- 小学：天气、植物、食物、习俗和家庭生活。
- 初中：物候、诗文、地域文化、生活方式和文化传承。
- 高中：时间意识、审美经验、文化变迁和传统的当代表达。

## 载体路由

### 传统手绘黑板

适合初中、高中和部分小学高段。输出完整黑板正视图，使用粉笔、水粉、广告画颜料、线描或版画语言，重点表现字图关系、板面空间和可参考绘制性。

### 黑板加卡纸剪贴

小学常用，初中可少量使用。第一轮仍输出完整板面预览，可以出现卡纸标题、照片框、剪纸、栏目牌、小报和装饰卡片；丰富来自简单模块的组合，不来自复杂写实。

### 软板／展板

主要用于小学、中队角和主题展示，不作为高中默认模式。先生成完整软板效果，标题牌、栏目牌、内容卡和装饰元素应有可拆分感；选案后再进入可打印素材模式。高中只在完整手绘黑板两侧少量附加材料，不把拼贴作为主体。
