# 黑板报图像语法蒸馏 v1.1

本文件是研发说明，不是运行依赖。核心规则已写入 `SKILL.md`。

## 1. 黑板报不是固定分区模板

优秀初高中黑板报常以一条主要走势统摄画面：红绸、海浪、山势、道路、书卷、花枝、光线或标题笔势。标题可横、竖、斜、环绕或嵌入，正文沿画面空域和走势进入，不必全部放入矩形框。

## 2. 六种柔性语法

- 流线长卷：一条主要走势贯穿全板；
- 主景环绕：主视觉与正文互相围合；
- 题字驱动：标题笔势成为主要构图力量；
- 双叙事：历史与当下、传统与创新等关系被视觉连接；
- 手绘视觉特刊：书页、器物、人物片段和文字被统一气氛连接；
- 模块软板：小学标题牌、内容卡、照片、小报与剪纸可拆组合。

## 3. 学段进阶

- 小学：具体生活、简单元素、丰富模块、可剪贴可制作；
- 初中：去儿童化，出现少年感、主景与文字穿插；
- 高中：历史、伦理、未来和个人位置，形成横向长卷、视觉随笔和字图共生。


## 4. 主题跨学段，表达分学段

社会主义核心价值观、学生素养与五育、节气、中华优秀传统文化、红色精神、重大节日、传统节日、革命纪念日等都可以进入小学、初中和高中。学段差异不在于“能不能做”，而在于从何处进入、标题怎样命名、正文写到多深、选用什么意象，以及怎样连接学生的现实行动。用户指定的主题与关键词必须保留，再做适龄转译。

## 5. 内容充分性

- 小学低段：1个核心句＋2—4个小单元；
- 小学高段：3—5个内容单元；
- 初中：2—3段实质内容＋事实、问题或行动连接；
- 高中主题教育型：2—4段文字序列＋1—2条引文、题跋或短句；
- 节庆氛围与班级纪念型可减少正文，改用真实留言和祝福。

## 6. 高级感与可绘制性

高级感来自题字、构图、色彩、形体、字图关系和疏密节奏；不来自摄影级手部、皮肤、复杂三维材质、微小纹样或密集透视。

## 7. 三距离检查

- 5米：标题、主视觉、情绪；
- 2米：内容分布、阅读顺序；
- 近距离：事实、故事、观点、行动。
