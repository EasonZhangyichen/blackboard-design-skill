# 发布与传播指南

## 1. 推荐的发行结构

采用“一套源码，四种入口”：

1. **GitHub 仓库**：版本管理和唯一事实源；
2. **Release ZIP**：面向 Codex、TRAE、Claude Code、CodeBuddy 等技术用户；
3. **单文件 `SKILL.md`**：面向 Skill 社区、普通教师和只支持单文件的平台；
4. **`WEB-QUICK-PROMPT.md`**：面向千问、豆包、Kimi 等网页图片模式。

核心产品始终是根目录 `SKILL.md`。其他文件只增强安装、评测和传播，不能成为运行依赖。

## 2. 不建议只分享仓库主页给 AI

有些 AI 可以浏览 GitHub，但不会自动：

- 递归读取仓库；
- 找到根目录 `SKILL.md`；
- 注册为持久 Skill；
- 打开图片生成工具。

因此公开后应同时提供：

- 仓库主页；
- `SKILL.md` 的直接文件或 Raw 链接；
- Release ZIP；
- 网页快速提示词。

## 3. 不同受众应该收到什么

### 普通教师

推荐发送：

- 一句话介绍；
- GitHub 主页；
- 可直接下载的 `SKILL.md`；
- 一张“支持哪些平台、如何进入图片模式”的说明图。

### Skill 社区

如果只支持单文件：

- 上传 `SKILL.md`；
- 简介中放 GitHub 链接；
- 说明必须在具备图片生成能力时才能直接成图；
- 不承诺所有平台画质一致。

推荐简介：

> 面向中国大陆小学、初中和高中教师的黑板报整图生成 Skill。输入学段、主题和板面形式，即可生成推荐主案、风格强化案和简化实操案，并附文字真值稿与设计理念。支持传统手绘黑板、小学拼贴软板、跨学段德育主题、局部修改和可打印素材。

### Agent / Vibe Coding 用户

推荐发送 Release ZIP 或仓库克隆命令。完整包包含：

- 核心 `SKILL.md`；
- 平台适配指南；
- 网页快速提示词；
- 测试用例；
- 验证脚本。

### 网页图片模式用户

推荐发送 `WEB-QUICK-PROMPT.md`，并提醒：

1. 先进入图片生成入口；
2. 一次提供学段、主题、育人方向和板面载体；
3. 平台一次只能生成一张时，按 A、B、C 顺序生成。

## 4. GitHub Release 建议

每个正式版本附：

- `SKILL.md`；
- `blackboard-design-skill-vX.Y.Z.zip`；
- `WEB-QUICK-PROMPT.md`；
- Changelog。

Release 标题示例：

> Blackboard Design Skill v0.7.1｜跨学段主题兼容与发行校准版

## 5. 小红书传播建议

内容结构建议：

1. 真实教师痛点：设计费时、模板低龄、图文难融合；
2. 演示输入只需三项：学段、主题、载体；
3. 展示小学、初中、高中差异；
4. 展示 A / B / C 三案与二轮局部修改；
5. 说明 Codex、WorkBuddy、千问工作台、豆包工作模式、TRAE 等入口；
6. 给出 GitHub 仓库和单文件下载方式。

不要把一般参考图宣传成官方效果上限。未来只有经过作者复核的黄金案例才进入 Showcase。

## 6. 私有到公开的发布顺序

1. 建立 private 仓库；
2. 运行验证脚本；
3. 在 Codex、WorkBuddy、千问工作台和豆包至少各完成一个回归任务；
4. 检查仓库无密钥、个人文件和版权不明图片；
5. 选择正式许可证；
6. 创建版本标签和 Release；
7. 将仓库改为 public；
8. 再开始对外传播。
